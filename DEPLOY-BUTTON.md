# Deploy to Azure

Use the portal link below after uploading stat.zip to Azure Blob Storage and generating a read-only SAS URL.

https://portal.azure.com/#create/Microsoft.Template/uri/https%3A%2F%2Fraw.githubusercontent.com%2Fpaulsonsunny19%2Fsentinelautomationmodules%2Fstat-upstream-azure-fix%2Fazuredeploy.json

This deployment uses System Assigned Managed Identity, the recommended upstream STAT identity mode.
