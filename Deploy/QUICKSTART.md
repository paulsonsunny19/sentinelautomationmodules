# Quick start

1. Upload upstream `stat.zip` v2.3.0 to private Azure Blob Storage.
2. Generate a read-only Blob SAS URL.
3. Open the deployment URL in `DEPLOY-URL.txt`.
4. Select the target subscription/resource group and region.
5. Paste the Blob SAS URL into `FunctionPackage`.
6. Deploy with System Assigned identity.
7. Run the official upstream STAT permissions procedure.
